# Windows Server Lab

Lab personnel autour de Windows Server 2022 et des principaux services d'infrastructure Microsoft.

## Objectif

Documenter la mise en place et l'administration d'un environnement Windows Server comprenant notamment :

- Active Directory Domain Services
- DNS
- DHCP
- Group Policy Objects (GPO)
- Windows Deployment Services (WDS)
- Gestion des utilisateurs et des groupes
- Intégration de postes Windows au domaine
- Administration et dépannage

## Environnement

- Windows Server 2022
- Machines clientes Windows
- VirtualBox
- Réseau virtualisé

## Compétences mises en pratique

- Installation et configuration de Windows Server
- Création et administration d'un domaine Active Directory
- Gestion des comptes utilisateurs et groupes
- Configuration DNS et DHCP
- Création et déploiement de GPO
- Déploiement de systèmes via WDS
- Intégration de postes clients au domaine
- Diagnostic et résolution de problèmes

## Architecture

La documentation de l'architecture du lab sera ajoutée progressivement avec :

- schémas réseau
- captures d'écran
- procédures de configuration
- commandes d’administration et de diagnostic
- scénarios de dépannage

## Progression

Ce dépôt sera enrichi au fur et à mesure avec les différentes étapes du lab et les procédures associées.
